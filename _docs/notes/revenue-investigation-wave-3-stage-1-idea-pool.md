# Revenue Investigation — Wave 3 Stage 1 Idea Pool

## Purpose

Wave 3 adds another **60 materially different opportunities**. The goal remains breadth before development. Ideas that merely duplicate earlier alert feeds, generic templates, directories, calculators, document extraction, or generic website monitoring are excluded.

## Current distribution context

Current platform documentation confirms that third-party business apps can be sold through ecosystems such as monday.com and Microsoft Marketplace. monday.com currently provides native app billing and reports more than 1.6 million marketplace app installs; Microsoft supports monetized SaaS offers linked to Teams/Microsoft 365 apps. These are potential distribution channels, not evidence that any specific idea below has demand.

Sources:
- https://developer.monday.com/apps/docs/monetization
- https://monday.com/w/app-developers
- https://learn.microsoft.com/microsoftteams/platform/concepts/deploy-and-publish/appsource/prepare/monetize-overview
